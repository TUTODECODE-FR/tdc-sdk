# 🎨 Extension VS Code : TUTODECODE Script (`.tdc`)

Extension officielle pour la prise en charge du langage de cours souverain **`.tdc` (TUTODECODE Course DSL v2)** dans Visual Studio Code, Cursor et VSCodium.

---

## 🚀 Fonctionnalités

- **Coloration Syntaxique Avancée** : Prise en charge des mots-clés (`course`, `module`, `quiz`, `question`, `category custom`, `codeblock`, `accent`, `author`), chaînes multilignes `""" ... """`, et propriétés.
- **Snippets Intelligents** : Tapez `tdc-course`, `tdc-module`, `tdc-quiz`, `tdc-question`, ou `tdc-codeblock` pour générer automatiquement les structures de blocs.
- **Appairage d'accolades & Indentation automatique**.
- **Gestion des commentaires** (`//` et `#`).

---

## 📦 Installation Facile

### Option A : Depuis l'interface VS Code
1. Téléchargez le fichier [`vscode-tdc-language-1.0.0.vsix`](./vscode-tdc-language-1.0.0.vsix).
2. Dans VS Code, ouvrez l'onglet **Extensions** (`Ctrl+Shift+X` ou `Cmd+Shift+X`).
3. Cliquez sur le menu `⋯` en haut à droite $\rightarrow$ **Install from VSIX...**.
4. Sélectionnez le fichier `.vsix`.

### Option B : En ligne de commande
```bash
code --install-extension vscode-tdc-language-1.0.0.vsix
```
